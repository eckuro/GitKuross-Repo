# Nordic Oracle Fusion (Cloud ERP) user scan, October 2026

Built from job postings, with vendor and partner references as a cross-check. Manufacturing comes first, for the Huhtamaki conversation. The full list is in `nordic_oracle_fusion_scan_2026-10.xlsx`.

## Headline
- Very few large Nordic manufacturers run Oracle Fusion ERP. Most use SAP (Wärtsilä, Konecranes), Infor (Valmet) or Dynamics 365 (Radiometer). That makes Huhtamaki one of only a few Nordic manufacturers on Oracle Fusion ERP.
- The closest manufacturing peers found:
  - **Vertiv's Nordic entity:** a Finance Controller role asks for Oracle ERP experience, either EBS or Fusion. Vertiv runs Oracle Cloud ERP globally.
  - **Georg Fischer/Uponor (Nastola):** the stack is Oracle-based, but it is not confirmed whether that means EBS or Fusion.
  - **Gränges:** runs Oracle EBS on OCI, so it is a candidate to move to Fusion rather than a Fusion user today.
- Confirmed Oracle Fusion ERP users outside manufacturing:
  - Skanska, Telenor, Securitas, HUS, Finnlines, SEB, an unnamed Nordic bank, DTU, Aalto University and the City of Espoo.
  - Falck, Nokia and Økonomistyrelsen use Fusion HCM only.

## Coverage caveat
LinkedIn, Duunitori, Jobindex, Finn.no and Platsbanken could not be opened directly from the research environment. The scan therefore relies on postings that web search has indexed, so it is a checked starting list and not a full count of the market. The `Search strings` tab has the Boolean and TheirStack filters needed to finish the count.
